# Caixa by VagasIO

Repositório oficial do Caixa, na conta `caixabyvagasio`. Plataforma SaaS multissegmento de gestão comercial e PDV, com V1 priorizando varejo geral.

## Estado

Base inicial de desenvolvimento. Veja a [concepção funcional](docs/concepcao-funcional.md) e o [guia da V1](docs/caixa-v1/README.md).

**Não é produção:** não use com dados reais. Não há PostgreSQL, persistência garantida, backups, pagamentos eletrônicos, emissão fiscal, multifilial nem operação offline.
